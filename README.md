# 📊 INFO 201: Data Analysis & Visualization Project

## 📝 Project Overview
This project was completed as part of **INFO 201: Foundational Skills for Data Science** at the **University of Washington**. Our goal was to analyze and visualize economic trends using real-world data sources, focusing on the relationship between **U.S. housing costs**. **Inflation**, and the **S&P 500**.

## 📂 What We Did 
We used **R** and **R Markdown** to:
- Import and clean multiple datasets, including **S&P 500 stock data**, **cost of living data**, and **consumer price index (CPI) data**.
- Process and transform data to ensure consistency, filtering by relevant years (2000–2023).
- Generate **interactive visualizations** using `ggplot2` to explore trends in housing costs and stock market performance.
- Identify potential correlations between the housing market and stock market movements.
- Implement best practices for **data cleaning**, **error handling**, and **report formatting**.

## 📊 Data Sources
We worked with:
- 📈 **S&P 500 Monthly Data** (historical closing values)
- 🏠 **U.S. Cost of Living and Housing Data**
- 💰 **Consumer Price Index (CPI) from the Federal Reserve**

## 🔧 Technologies Used
- **R & R Markdown** 📄
- **tidyverse (dplyr, ggplot2, readr, lubridate, tidyr, purrr)** 🛠️
- **knitr** for report generation 📝
- **GitHub** for version control & collaboration 🌐

## 📜 Final Report
Our final analysis and visualizations were compiled in an **R Markdown report**, which can be found in this repository.
